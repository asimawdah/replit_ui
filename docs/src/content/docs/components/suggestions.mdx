`ReplitSuggestion` is one prompt starter as a tappable row, in two variants:
plain rows in the secondary ink, and `outlined` rows on a faint fill in
full ink. `ReplitSuggestionGroup` arranges them in the layout the surface
needs. Taps report back through each row's `onTap`; sending the prompt is
the host's move. A row without a callback renders disabled. On devices
that hover, a row washes in the faintest container ink and lifts its
content to full strength — and in a column on the web, a trailing arrow
appears as the send affordance.

## Column

Full-width plain rows are the design's primary form — the zero state's
starters:

<ReplitDemo demo="suggestions" variant="column" height={300} title="Column layout" />

```dart title="The zero state's starters"
ReplitSuggestionGroup(
  // The design's primary form: full-width plain rows, 6px apart.
  layout: ReplitSuggestionLayout.column,
  suggestions: [
    ReplitSuggestion(
      label: 'Write an essay about life and enjoyment',
      icon: Icons.article_outlined,
      onTap: () => send('Write an essay about life and enjoyment'),
    ),
    ReplitSuggestion(
      label: 'Create a Monday briefing about my tasks',
      icon: Icons.event_available_outlined,
      onTap: () => send('Create a Monday briefing about my tasks'),
    ),
  ],
)
```

## Scrolling strip

The default layout is one strip that scrolls, no scrollbar — the form for
follow-up suggestions above a composer. `outlined: true` draws each row on
the faint fill and hairline:

<ReplitDemo demo="suggestions" variant="scroll" height={200} title="Scrolling strip" />

```dart title="Outlined rows in a strip"
ReplitSuggestionGroup(
  // The default: one strip that scrolls, no scrollbar. outlined
  // draws each row on the faint fill and hairline, in full ink.
  suggestions: [
    for (final prompt in prompts)
      ReplitSuggestion(
        label: prompt,
        outlined: true,
        onTap: () => send(prompt),
      ),
  ],
)
```

## Wrap

`ReplitSuggestionLayout.wrap` flows the rows like chips. A suggestion
without `onTap` renders disabled — its `tooltip` can say why:

<ReplitDemo demo="suggestions" variant="wrap" height={260} title="Wrap layout" />

```dart title="Wrapped, with a disabled row"
ReplitSuggestionGroup(
  layout: ReplitSuggestionLayout.wrap,
  suggestions: [
    ReplitSuggestion(
      label: 'Summarize this thread',
      icon: Icons.summarize_outlined,
      outlined: true,
      onTap: () => send('Summarize this thread'),
    ),
    // No onTap → disabled.
    ReplitSuggestion(label: 'Run a deep research pass', outlined: true),
  ],
)
```

## Above a composer

The pattern hosts copy: starters that fill the field, gone once the
thread starts. An empty `suggestions` list takes no space, so the column
collapses cleanly:

```dart title="Starters that hand off to the field"
Column(
  children: [
    ReplitSuggestionGroup(
      // Empty once the thread starts — the group then takes no space.
      layout: ReplitSuggestionLayout.column,
      suggestions: [
        for (final prompt in starters)
          ReplitSuggestion(
            label: prompt,
            onTap: () => controller.text = prompt,
          ),
      ],
    ),
    const SizedBox(height: 8),
    ReplitComposer(controller: controller, onSend: send),
  ],
)
```

## Restyling

`ReplitSuggestionStyle` overrides a suggestion's colors without touching
the global tokens: `backgroundColor`, `borderColor` (the outlined form's
hairline), `hoverColor`, `foregroundColor`, and `labelStyle` (merged over
the default). Install one on `ReplitTheme.suggestionStyle` for every
suggestion; the widget's `style` wins field by field.

## Key API

- `ReplitSuggestion` — `label`, optional `icon`, `outlined`, `onTap`,
  `tooltip`; no `onTap` → disabled, as does `enabled: false`. `padding`
  and `borderRadius` override the design's 36px row (10 inside, an 8px
  corner).
- `ReplitSuggestionGroup` — `suggestions` + `layout`
  (`ReplitSuggestionLayout.scroll` default, `.column`, `.wrap`), plus
  `spacing` (the design's 6 in a column, 10 otherwise) and `padding` —
  which scrolls with the strip, so the first and last rows clear the
  edge.
- `ReplitSuggestionColumnScope` — what the column layout wraps its rows in
  so a hovered row shows the trailing arrow; public so a host laying out
  its own full-width column can opt in.
- `ReplitChatView` places a column group in its zero state via the
  `suggestions:` slot.
